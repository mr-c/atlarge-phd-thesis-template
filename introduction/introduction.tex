\section{Background \& Context}

rise of computational approaches in biology
biology / bioinformatics differs from other fields:
- many many researchers
- working in many different geographies
- towards different goals
- data collection machines are relatively less expensive and much smaller than other fields, so there is no central coordiation like LHC/CERN
- different niches/needs within biology led to highly customized approaches, no "one-size-fits-all" tools nor tool usage; tool-choice, & parameter-choice are both critical, and custom code analysis code abounds to account for species or disease-specific differences, and unique experimental designs.

All of the above is a mess, researchers started using workflow techniques to cope; low- to no-structure in some places, highly structured in others.

This hurt interop, lots of duplicate efforts. Hindered the full realization of the benefits of a workflow approach.
